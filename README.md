# 🛍️ E-commerce Sales Analysis Dashboard (Excel)

An interactive Excel dashboard analyzing **31,047 online fashion orders** from Indian e-commerce platforms (2022), built with pivot tables, charts and slicers.

## 📊 What's Inside
- Sales by channel, category, city and state
- Monthly sales trend
- Customer split by gender
- Orders by status (delivered, returned, cancelled, refunded)

## 🔍 Key Insights
- Total sales: about ₹21.4M
- Top channel: Amazon | Top category: Set | Top state: Maharashtra
- About 69% of orders are from women
- About 92% of orders were delivered

## 📂 Dataset
`Ecommerce data` sheet: 31,047 rows × 17 columns (Order ID, Gender, Age, Date, Status, Channel, Category, Size, Qty, Amount, ship-city, ship-state, etc.)

## 🛠️ Tools
Microsoft Excel · Pivot Tables · Pivot Charts · Slicers

## 🚀 How to Use
Download `Ecommerce_dataset_Raw.xlsx`, open it in Excel and go to the `DashBoard` sheet.
